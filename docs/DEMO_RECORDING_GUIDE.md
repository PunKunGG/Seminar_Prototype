# คู่มือเตรียมคลิปสาธิตพฤติกรรม

เอกสารนี้เป็นแผนการถ่ายคลิปจริง ยังไม่ใช่ชุดคลิปที่ผ่านการวัดความแม่นยำ ภาพ/คลิปสังเคราะห์ใน software tests ใช้ทดสอบโปรแกรมเท่านั้น ห้ามใช้เป็นหลักฐานว่าระบบตรวจพฤติกรรมจริงได้แม่นยำ

## การถ่าย

- ขออนุญาตผู้ร่วมคลิปและกำหนดผู้ที่เข้าถึงไฟล์ก่อนถ่าย ใช้กล้องมุมคงที่ในห้องแล็บจริง ให้เห็นคนและจุด pose ที่ต้องใช้ แสงเพียงพอ ไม่ใช้คลิปเกมแทนคนจริง
- ใช้ MP4/H.264 สำหรับเล่นใน browser ถ่ายกรณีเข้าเกณฑ์และกรณีคล้ายที่ไม่ควรเข้าเกณฑ์แยกกัน เริ่มและจบแต่ละคลิปด้วยท่านั่งปกติ 15 วินาที
- ท่าหลับจำลองให้ถ่ายอย่างน้อย 3 นาที ไม่จำเป็นต้องหลับจริง เกณฑ์รายงานใช้ 120 วินาทีที่ตรวจจริงหลังยืนยันสถานะ ไม่ใช่แค่ความยาวคลิป
- พฤติกรรมอื่นให้ค้างท่าอย่างน้อย 45-60 วินาที เผื่อการยืนยันสถานะและเกณฑ์ 30 วินาที คลิปยาวที่สุ่มตรวจจะไม่รวมเวลาระหว่างหน้าต่างตรวจ
- เก็บคลิปใน `backend/video_sources/demo/` ซึ่งถูก ignore อยู่ ไม่ใส่ไฟล์วิดีโอหรือข้อมูลระบุตัวบุคคลลง Git

## รายการคลิป

| พฤติกรรม | ตัวอย่างเข้าเกณฑ์ | ตัวอย่างเปรียบเทียบ |
| --- | --- | --- |
| ตั้งใจเรียน | นั่งลำตัวตรง ศีรษะสูงกว่าไหล่ มองจอหรือผู้สอน | ก้มอ่านเอกสารโดยลำตัวตรง ระบบอาจแยกการเรียนจากกิจกรรมอื่นไม่ได้ |
| ท่าเข้าข่ายหลับ | ศีรษะต่ำใกล้ไหล่และลำตัวพับ/เอน ค้างอย่างน้อย 3 นาที | ก้มเก็บของ 10-20 วินาที, ท่าคล้ายหลับต่ำกว่า 120 วินาที, ก้มอ่านแต่ลำตัวตรง |
| ก้มหน้า | ลดศีรษะใกล้ไหล่โดยไม่พับลำตัว | มองจอที่อยู่ระดับต่ำ ต้องบันทึกบริบทว่าจออยู่ตรงไหน |
| ใช้โทรศัพท์ | ถือโทรศัพท์ที่มองเห็นชัดใกล้ลำตัว | มือบังโทรศัพท์, โทรศัพท์ของคนข้างกัน ไม่ควรสรุปว่าตรวจพบวัตถุได้แน่นอน |
| สงสัยใช้โทรศัพท์ | มือสองข้างใกล้กันต่ำกว่าไหล่ ปลายแขนบรรจบ | ประสานมือหรือพิมพ์คอม ต้องระบุว่าท่าคล้ายไม่ใช่การใช้โทรศัพท์จริง |
| ยกมือ | ข้อมือเหนือใบหน้า สูงกว่าศอก ศอกใกล้ระดับไหล่ | จับคาง เกาศีรษะ และโบกมือชั่วครู่ |
| ยืน/ลุก | ลุกยืนให้เห็นสะโพก เข่า และข้อเท้า | นั่งขาเหยียด, ยืนแต่ขาถูกโต๊ะบัง |
| ไม่ชัดเจน | ถูกบังจนจุด pose ไม่พอหรือมีสัญญาณขัดแย้ง | คลิปภาพชัดของท่าเดียวกัน |

เพิ่มคลิปสองคนข้างกัน สลับลำดับการมองเห็น และลุกออกจากกล้องแล้วกลับที่เดิมเพื่อดู ID ความผิดพลาดของ ID ต้องแยกจากความผิดพลาดของพฤติกรรม

## คำตอบอ้างอิง

กรอก `DEMO_GROUND_TRUTH.csv` โดยคนก่อนรัน AI ระบุบุคคลด้วยรหัสผู้ทดสอบที่ไม่ใช่ชื่อจริง และจับคู่กับ ID ที่ระบบออกให้เฉพาะรอบนั้น คำตอบอ้างอิงต้องไม่สร้างจาก prediction ของระบบ

บันทึกทั้งช่วงที่ท่าตรงเกณฑ์และกิจกรรมจริง เช่น ประสานมืออาจเข้า pose สงสัยโทรศัพท์ แต่กิจกรรมจริงไม่ใช่โทรศัพท์ การดูคลิปย้อนหลังช่วยตรวจสอบ ไม่ได้ทำให้ prediction กลายเป็นข้อเท็จจริง

## การสาธิตต่อกรรมการ

1. แสดงเกณฑ์และข้อจำกัด รวมถึงช่วงสรุป เวลายืนยัน และขั้นต่ำในรายงานที่แยกกัน
2. อัปโหลดคลิป สร้างรอบใหม่ และเปรียบเทียบรายงานกับตารางคำตอบที่กรอกไว้
3. กดดูหลักฐานของ ID เล่นช่วงที่ตรวจจริง และตรวจพฤติกรรมจากคลิปต้นฉบับด้วยคน
4. แสดงเคสผิดพลาดและเคสที่ระบบตอบไม่ชัดเจน ไม่เลือกแสดงเฉพาะเคสสำเร็จ
